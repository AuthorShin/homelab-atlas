# Homelab Atlas v0.20.1

## Changed

The img2svg vectorizer now runs at maximum fidelity: 64 colors, native gradient detection, high coordinate precision, strict curve tolerance, median recoloring, corner and curve optimization, and despeckling disabled so small details are retained.

## Upgrade from 0.20.0

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
