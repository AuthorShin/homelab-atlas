# Homelab Atlas v0.19.9

## Delete uploaded logos

Uploaded logos in the Logo catalog now have a delete action. Deleting removes the logo from the project and deletes its stored SVG from the server. If the logo is currently used by a device, service, network node, group, or the app logo, the delete is blocked and the usage is named in the message.

Group logo and app logo uploads are also registered as uploaded logos in the catalog now, so they can be reused or deleted like logos added from the picker.

## SVG DOCTYPE support

Uploaded SVGs that begin with the standard SVG 1.1 `DOCTYPE` declaration are accepted and stored as-is. Other DOCTYPE forms, `ENTITY` declarations, scripts, event handlers, external URLs, and animations remain rejected.

## Upgrade from 0.19.8

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
