# Homelab Atlas v0.18.0

## Themes

**Diagram settings → Manage themes** opens a gallery of themes. Each theme has its own name, custom CSS, background image, and **Background placement** (`Stage and diagram`, `Stage only`, or `Diagram only`). Use a theme to activate it; add, duplicate, edit, and delete themes from the gallery.

**Random background each day** picks one gallery background from the calendar date. The choice is deterministic, so the editor and dashboard always show the same image on a given day. The active theme still supplies the CSS and background placement.

The old project **Custom CSS** box and project-level background controls are gone. They migrate into a starting theme when an older project opens. Theme CSS is applied in the editor and dashboard, but never written into SVG or PNG exports.

## Service icon and label controls

Every service now has **Icon size** (16–64 diagram units) and **Show name** controls in the inspector. Icon size applies in both grid tiles and service rows; very large values are limited by the available tile height. Turning off **Show name** hides the label and keeps the full name as a hover tooltip. Long labels are always rendered on one line with an ellipsis, with the complete text in the tooltip.

Groups with a logo now show the 32px logo with the group name beside it, vertically centered, instead of placing the name under the icon.

## Flat interface

The `--line` and `--line-soft` CSS variables and the borders that used them are removed, including the top-bar divider. The interface no longer draws those separator lines.

## Upgrade from 0.17.0

Recreate the container with the new Compose file. The `atlas-data` volume is reused, including uploaded images and the autosaved default project.

The project schema is now version 12. Schema versions 1 through 11 still open and migrate automatically; the old CSS/background pair becomes a starting theme, and services gain `iconSize` and `showName`. Atlas does not migrate projects backward, so 0.17.0 and older cannot open a schema-12 project.

Open **File → Save project** before updating and keep the ZIP. It contains the project and every uploaded image, including theme backgrounds.
