# Homelab Atlas v0.20.0

## Gradient-capable tracing

The vectorizer now uses [img2svg](https://github.com/yingkitw/img2svg) instead of OpenVector. With its gradient detection enabled, smooth regions become native SVG `<linearGradient>` and `<radialGradient>` fills rather than flat color bands, so uploaded raster logos with gradients look much closer to the source artwork.

The async job flow, progress bar, SVG validation, and all upload APIs are unchanged. SVG uploads are still stored as-is.

Note: tracing approximates the source; it cannot reproduce the exact vector markup from an original SVG file. Upload the SVG itself when you need an exact match.

## Upgrade from 0.19.14

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
