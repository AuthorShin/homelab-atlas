# Homelab Atlas v0.19.10

## Fixes

- Uploaded-logo deletion now scans the whole project for references to the logo ID or its upload URL before deleting the file, preventing broken references that made **Save project** fail with HTTP 404.
- The uploaded-logo delete button has a proper circular button shape and a cleaner danger-colored hover state.
- The diagram group logo is now 28px instead of 32px.

## Upgrade from 0.19.9

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
