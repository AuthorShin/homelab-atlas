# Homelab Atlas v0.19.1

## Restored control borders

The `--line` and `--line-soft` CSS variables are back, along with the borders that use them. Inputs, selects, text areas, buttons, dialogs, cards, the zoom dock, panels, and the top-bar divider are framed again, matching the appearance before v0.18.0.

The theme gallery, the standardized group-logo remove button, and the OpenVector vectorizer from v0.18.0 and v0.19.0 are unchanged.

## Upgrade from 0.19.0

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
