# Homelab Atlas v0.16.0

## Branding in the project

App branding now lives in the project JSON instead of the server-wide `branding.json`. The name, optional browser-tab title, and logo are edited under **Diagram settings → App branding** and travel with the project. The editor and dashboard both read `project.branding`; the old server branding endpoint is no longer used by the UI. The logo precedence is unchanged: project app logo, then project tab icon, then the default Atlas mark.

## Default project autosave

**Save as default project** and **Clear default project** are gone. Every project change now debounces a PUT to `/api/default-project`, so the current project is saved automatically to the `atlas-data` volume. A fresh browser or new device still loads the server default when it has no usable local autosave.

## Per-group side-by-side layout

The per-device **Side-by-side groups** toggle is replaced by a checkbox on each service group. Tick the groups you want to place side by side; they use the **Columns** value from **Diagram appearance**. Unticked groups stack full width. Older projects migrate their per-device setting into the new per-group flags.

## Images on the server

Image fields now use `/data` upload references instead of embedded data URLs. New uploads for the app logo, project tab icon, custom logos, group logos, and background image are stored by `/api/uploads`. **File → Move embedded images to Atlas** uploads existing data URLs in an open project and replaces them with server references so they can be shared from the `atlas-data` volume.

## Exports

The background image is now drawn inside the exported SVG, behind all diagram content and sized to the full viewBox. Service links, favicons, app branding, and custom CSS remain outside SVG and PNG exports.

## Custom CSS guide

A new **Custom CSS** documentation page covers project CSS, including which parts of the app it can style and where it does not apply.

## Schema 10

The project schema moves from version 9 to version 10. Version 10 adds `branding` and per-group `sideBySide`, and removes `device.groupLayout`. Schema-9 projects migrate automatically: the old device setting becomes per-group flags and a default branding block is added. Schema 10 still has no `discovery` field.

## Upgrade from 0.15.x

Recreate the container with the new Compose file. The existing `atlas-data` volume is reused, so uploaded images and the autosaved default project are kept. Branding now lives in the project, so copy it into each project that needs it. Keep a JSON backup before downgrading, because older Atlas versions cannot open schema-10 projects.
