# Homelab Atlas v0.19.4

## Tracing export fix

OpenVector can write an XML declaration before the `<svg>` root element. The vectorizer previously required the file to start with `<svg`, so every traced upload was rejected with `export produced no SVG (status 0)`. The declaration is now accepted and stripped before the SVG is stored.

If the fast fixed-color profile produces no fitted geometry, that image is retried once with the automatic profile. Images that still cannot be traced are reported by **File → Convert existing images to vectors** without stopping the other conversions.

## Editor fixes

- Service **Icon size** values up to 64 are rendered exactly as entered without changing tile heights. Above 40 units the label is hidden automatically (the full name stays in the tooltip) and the inspector shows a **Label hidden** hint.
- The **Side by side** checkbox label is hidden until the group is selected or focused, then renders on one row with the checkbox.

## Upgrade from 0.19.3

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
