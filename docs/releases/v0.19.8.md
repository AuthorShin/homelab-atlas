# Homelab Atlas v0.19.8

## Maximum tracing fidelity

Logo tracing now uses the highest fixed advanced settings available: 24 colors, complexity 12, curve complexity 12, smoothness 12, maximum sensitivity, no minimum-pixel filtering, no artifact rejection, and preserved background. This is intended to keep internal shapes and fine detail in illustrations that were previously flattened.

The automatic profile is still used as a fallback when the fixed profile produces no fitted geometry. Tracing remains asynchronous with progress, so higher-quality settings do not cause proxy timeouts.

## Upgrade from 0.19.7

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
