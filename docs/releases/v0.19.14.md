# Homelab Atlas v0.19.14

## Added

The Logo catalog now has **Delete all uploaded**. It deletes every uploaded image file from the server and clears all custom upload references across the project, including stale hashes left by older versions. Theme backgrounds are kept.

## Upgrade from 0.19.13

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
