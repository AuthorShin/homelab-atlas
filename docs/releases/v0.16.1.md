# Homelab Atlas v0.16.1

## Project ZIP save and import

**File → Save project** now downloads one ZIP archive containing `project.json`, a small manifest, and every uploaded image the project uses under `uploads/`. **File → Import project** restores that archive and uploads its images to the Atlas instance you are importing into, so a project can move between servers without losing logos, group logos, tab icons, or backgrounds.

Legacy JSON exports from schema versions 1 through 9 are still accepted as a migration path. Atlas validates the old project, uploads any embedded images, and saves the result as schema version 10. There is no JSON export in the File menu.

## Embedded-image migration is automatic

**File → Move embedded images to Atlas** has been removed. New uploads are always stored by `/api/uploads` and referenced from the project. Existing embedded data URLs continue to open, and they are converted automatically when an old JSON project is imported.

## Group editing fixes

- Group names now render directly under the group logo, so the label is not hidden by the image.
- The group logo remove button sits beside the logo instead of overlapping it.
- The **Side by side with other marked groups** checkbox appears only while its group is selected or focused. The label now describes what the option does.
- Newly created groups include the required `logo` and `sideBySide` fields. This fixes the validation error `Group logo must be empty or a valid image upload reference` when adding a group or service, and it fixes the group **Apps** picker.
- Schema-10 projects saved by 0.16.0 without those two group fields are repaired when they load, so existing autosaves open normally.

## Upgrade from 0.16.0

Recreate the container with the new Compose file. The `atlas-data` volume is reused, including uploaded images and the autosaved default project.

Before making a large change, open **File → Save project** and keep the ZIP. It replaces the old JSON backup and includes every uploaded image. Older Atlas versions cannot import a project ZIP, so keep the 0.16.0 JSON backup as well if you may downgrade.

The project schema remains version 10. Service links, favicons, branding, custom CSS, and the background image remain excluded from SVG and PNG exports.
