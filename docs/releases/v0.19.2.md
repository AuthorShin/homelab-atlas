# Homelab Atlas v0.19.2

## Line variables disabled

The `--line` and `--line-soft` declarations in `styles.css` and `dashboard.css` are commented out. The declarations that reference them are unchanged, so borders and divider lines that used those variables are no longer drawn. This matches unchecking the two variables in browser DevTools.

The theme gallery, the standardized group-logo remove button, and the OpenVector vectorizer are unchanged.

## Upgrade from 0.19.1

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
