# Homelab Atlas v0.17.0

## Choose where the background image appears

**Diagram appearance** now has a **Background placement** setting:

- **Stage and diagram** keeps the previous behavior: the image appears around the diagram and behind its content.
- **Stage only** keeps the image on the canvas around the diagram.
- **Diagram only** draws the image behind devices and cards, including in SVG and PNG exports, without repeating it around the canvas.

Projects saved by earlier versions migrate with **Stage and diagram**, so their appearance does not change.

## Larger background uploads

Background images can now be up to 10 MB. Other image uploads keep their 2 MB limit. The limit applies consistently to uploads, project ZIP import and export, and validation.

## Logos are stored as SVG

Uploaded custom logos and group logos are now stored as SVG instead of PNG. Atlas renders the source image at up to 512px and embeds it in a self-contained SVG container, so JPG, PNG, WebP, and SVG uploads all become SVG files. The app-branding logo and the browser-tab icon keep their separate 128px PNG pipeline.

## Side-by-side groups

Groups marked **Side by side** now hide the app labels inside their tiles and show only the app logos, keeping narrow rows readable. Hovering a tile still shows its app name.

## Fixes

- **File → Export** no longer fails with `Background must be empty or a valid image upload reference` when the project uses a large uploaded background. Export validates the stored project before inlining images.
- ICO images (`data:image/x-icon` and `data:image/vnd.microsoft.icon`) are accepted as background and group logo data URLs, matching ICO upload support.

## Upgrade from 0.16.1

Recreate the container with the new Compose file. The `atlas-data` volume is reused, including uploaded images and the autosaved default project.

The project schema is now version 11, adding `backgroundScope`. Schema versions 1 through 10 are still accepted and migrate automatically with `backgroundScope: "both"`. Atlas does not migrate projects backward; 0.16.1 and older cannot open a schema-11 project.

Open **File → Save project** before updating and keep the ZIP. It contains the project and every uploaded image, and it is the editable backup for moving between servers.
