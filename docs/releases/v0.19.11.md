# Homelab Atlas v0.19.11

## Fixes

- Group logo uploads now store the SVG upload reference instead of the catalog logo ID, fixing the validation error `Group logo must be empty or a valid image upload reference`. Existing autosaves that contain the invalid ID are repaired when they load.
- Group headers with a logo use the same height as headers without one, so side-by-side groups stay the same size. The icon-to-name gap was also reduced.

## Upgrade from 0.19.10

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
