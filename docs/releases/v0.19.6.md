# Homelab Atlas v0.19.6

## SVG export fix

OpenVector exports can begin with a `DOCTYPE` declaration before the `<svg>` root. The vectorizer previously tried to strip known prefixes and still rejected some valid exports with `export produced no SVG`. It now searches for the `<svg>` root anywhere in the export and keeps the file from there. The diagnostic error is retained for genuinely empty exports.

## Checkbox styling

All editor checkboxes now use accent-colored boxes with rounded corners and a clear white check when selected.

## Upgrade from 0.19.5

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
