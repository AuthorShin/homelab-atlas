# Homelab Atlas v0.19.5

## Vectorization with progress

Logo tracing no longer holds an HTTP request open. Atlas now creates a background job and returns immediately; the editor shows a progress bar and polls for the result. This applies to both new logo/app-logo uploads and **File → Convert existing images to vectors**. Slow traces can no longer produce a `502 Bad Gateway` from a reverse proxy.

## Better diagnostics

When OpenVector writes an unexpected export, the error now includes the file length and its first characters. The vectorizer strips UTF-8 BOMs, XML declarations, comments, and doctypes before checking for the `<svg>` root.

## Upgrade from 0.19.4

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
