# Homelab Atlas v0.19.3

## Faster, simpler tracing

Logo uploads now use a fixed 12-color advanced OpenVector profile instead of automatic classification and palette search. Tracing is much faster, which avoids the long CPU spike and the `502 Bad Gateway` you could see behind Nginx Proxy Manager. The tradeoff is that smooth gradients are approximated with color bands rather than reproduced exactly.

If you access Atlas through Nginx Proxy Manager, add `proxy_read_timeout 120s`, `proxy_send_timeout 120s`, and `client_max_body_size 12m` in the proxy host's **Advanced** tab so large background uploads and unusually slow traces are not cut off by the proxy.

## Better tracing errors

When an image produces no fitted geometry, the vectorizer now returns a descriptive `422` error (`image produced no vector regions`) instead of the generic `export produced no SVG`. Export status details are included in other failures.

**File → Convert existing images to vectors** now skips images that cannot be traced, converts the rest, and reports how many were skipped instead of aborting the whole action.

## Inspector layout

The service inspector's **Icon size** and **Show name** controls now span the full row beside the logo, so the label no longer wraps into the narrow logo column.

## Upgrade from 0.19.2

Recreate the containers with the new Compose file. The `atlas-data` volume is reused, including uploaded images, the autosaved default project, and the vectorizer service. The project schema is unchanged at version 12.
